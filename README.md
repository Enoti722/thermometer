# Usb Thermometer

## О проекте

Данное приложение позволяет подключать к вашей Android магнитоле USB-термометр. Поддерживается следующий функционал:

- Чтение температуры с термометра
- Виджет поверх всех приложений, отображающий температуру
- Настройка отображения виджета
- Уведомления об аномальных значениях, а так же о потере соединения с датчиком

Изначально приложение разрабатывалось и тестировалось для `Teyes CC3 2K` с Android 10 и датчика [ODTEMP-1U](https://unitx.pro/docs/sensors/odtemp/), однако в процессе разработки были испробованы разные варианты и, возможно, ваша магнитола/датчик так же поддерживаются.

Приложение основано на репозитории [usbSerialExamples](https://github.com/mik3y/usb-serial-for-android), который содержит исходный код библиотеки и примеры использования. Выражаем огромную благодарность авторам библиотеки!

## Состав репозитория

Основными в репозитории являются папки:

- usbSerialExamples - основное приложение на основе оригинального примера по использованию
- usbSerialForAndroid - оригинальная библиотека для работы с USB

## Поддерживаемые устройства

Оригинальная библиотека работы с USB поддерживает следующие USB to serial конвертирующие чипы:

- FTDI FT232R, FT232H, FT2232H, FT4232H, FT230X, FT231X, FT234XD
- Prolific PL2303
- Silabs CP2102, CP210*
- Qinheng CH340, CH341A, CH9102

А так же устройства, реализующие CDC/ACM протокол, такие как:

- Arduino using ATmega32U4
- Digispark using V-USB software USB
- BBC micro:bit using ARM mbed DAPLink firmware
- ...

И некоторые специфические драйверы:

- GsmModem devices, e.g. for Unisoc based Fibocom GSM modems
- Chrome OS CCD (Closed Case Debugging)
