Вы только что получили полную реализацию **эмуляции термометра** для вашего Android приложения!

## ⚡ Быстрый старт (3 шага)

### 1️⃣ Соберите проект

```bash
./gradlew clean assembleDebug
```

### 2️⃣ Установите на устройство

```bash
./gradlew installDebug
```

### 3️⃣ Запустите и выберите эмулятор

1. Откройте приложение
2. В списке устройств выберите **"Emulated Thermometer"**
3. Наблюдайте за температурой! 🌡️

## 🔍 Как это работает?

```
1. Вы выбираете "Emulated Thermometer" из списка
                    ↓
2. UsbService создает EmulatedThermometerDevice
                    ↓
3. Эмулятор подключается и запускает таймер
                    ↓
4. Каждую секунду генерируется новая температура
                    ↓
5. Данные отображаются в уведомлении и оверлее
```

## 💡 Примеры

### Создание эмулятора в коде

```java
IThermometerDevice emulator = new EmulatedThermometerDevice();

emulator.setDataListener(new IThermometerDevice.ThermometerDataListener() {
    @Override
    public void onTemperatureReceived(String temperature) {
        Log.d("Temp", "Received: " + temperature + "°C");
    }
    
    @Override
    public void onError(String error) {
        Log.e("Temp", "Error: " + error);
    }
    
    @Override
    public void onStatusChanged(String status, String statusIcon) {
        Log.i("Temp", statusIcon + " " + status);
    }
});

emulator.connect();
```
