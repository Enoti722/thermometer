# Быстрый старт с эмулятором термометра

## Что было сделано

✅ Создан интерфейс `IThermometerDevice` для абстракции работы с термометром  
✅ Существующий код обернут в `RealThermometerDevice` (без изменений логики)  
✅ Создан `EmulatedThermometerDevice` с генерацией случайных температур  
✅ Эмулятор добавлен в список устройств в `DevicesFragment`  
✅ `UsbService` обновлен для работы с обоими типами устройств  

## Как использовать

### Шаг 1: Запустите приложение

Откройте приложение на устройстве или эмуляторе Android.

### Шаг 2: Выберите эмулятор

В списке устройств вы увидите:
```
Emulated Thermometer
Test Device (No Physical Hardware)
```

Нажмите на это устройство.

### Шаг 3: Наблюдайте за данными

После подключения:
- В уведомлении будет отображаться текущая температура
- Оверлей покажет температуру и напряжение батареи
- Температура будет обновляться каждую секунду
- Значения будут плавно изменяться в диапазоне 15-35°C

## Что происходит внутри

1. **При выборе эмулятора:**
   - В SharedPreferences сохраняется `isEmulated = true`
   - Сохраняется специальный `deviceId = 999999`
   - UsbService перезапускается

2. **При запуске UsbService:**
   - Читается флаг `isEmulated`
   - Создается `EmulatedThermometerDevice` вместо `RealThermometerDevice`
   - Устанавливается слушатель данных

3. **При подключении:**
   - Эмулятор сразу "подключается" (без задержки USB)
   - Запускается таймер обновления температуры
   - Каждую секунду генерируется новое значение

4. **Генерация температуры:**
   - Начальная температура: 22°C
   - Случайно выбирается целевая температура (15-35°C)
   - Текущая температура плавно движется к целевой
   - Добавляется небольшой шум для реалистичности

## Переключение на реальное устройство

1. Подключите физический термометр через USB
2. Откройте список устройств
3. Выберите реальное устройство из списка
4. Приложение автоматически переключится на работу с USB

## Возможные проблемы

### Эмулятор не появляется в списке

**Решение:** Проверьте, что изменения в `DevicesFragment.refresh()` применены корректно.

### Температура не обновляется

**Решение:** 
1. Проверьте логи на наличие ошибок
2. Убедитесь, что `thermometerDevice.connect()` вызывается
3. Проверьте, что слушатель данных установлен

### Приложение падает при выборе эмулятора

**Решение:**
1. Проверьте, что все новые классы скомпилированы
2. Убедитесь, что в SharedPreferences корректно сохраняется `isEmulated`
3. Проверьте логи на наличие исключений
