# Эмулятор термометра

## Описание

Добавлена возможность эмуляции термометра для тестирования приложения без физического устройства.

## Архитектура

### Интерфейс IThermometerDevice

Создан интерфейс `IThermometerDevice`, который абстрагирует работу с термометром:

```java
public interface IThermometerDevice {
    boolean connect();
    void disconnect();
    boolean isConnected();
    void sendCommand(String command);
    int getDeviceId();
    int getPortNum();
    String getDeviceName();
    boolean isEmulated();
    void setDataListener(ThermometerDataListener listener);
}
```

### Реализации

1. **RealThermometerDevice** - обертка над существующим кодом работы с реальным USB устройством
   - Использует UsbSerialPort для связи с физическим термометром
   - Не изменяет существующую логику работы
   - Полностью совместим с оригинальным кодом

2. **EmulatedThermometerDevice** - эмулятор термометра
   - Генерирует случайные значения температуры в диапазоне 15-35°C
   - Плавно изменяет температуру (имитация реального поведения)
   - Обновляет данные каждую секунду
   - Не требует физического устройства

## Использование

### Выбор устройства

В списке устройств (DevicesFragment) теперь всегда отображается "Emulated Thermometer" в начале списка.

### Подключение

1. Откройте приложение
2. В списке устройств выберите "Emulated Thermometer"
3. Сервис автоматически подключится к эмулятору
4. Температура будет обновляться каждую секунду

### Переключение между реальным и эмулированным устройством

Просто выберите нужное устройство из списка. Сервис автоматически остановится и перезапустится с выбранным устройством.

## Технические детали

### Хранение настроек

В SharedPreferences добавлен новый флаг:
- `isEmulated` (boolean) - указывает, используется ли эмулятор

### ID эмулятора

Эмулятор использует специальный ID: `999999`

### Параметры эмуляции

- Начальная температура: 22.0°C
- Диапазон: 15.0 - 35.0°C
- Скорость изменения: до 0.5°C за итерацию
- Интервал обновления: 1000 мс (1 секунда)
- Добавлен случайный шум: ±0.1°C

## Преимущества

1. **Тестирование без оборудования** - можно разрабатывать и тестировать приложение без физического термометра
2. **Изоляция кода** - существующий код не изменен, только обернут в интерфейс
3. **Легкое переключение** - можно быстро переключаться между реальным и эмулированным устройством
4. **Реалистичное поведение** - эмулятор имитирует плавное изменение температуры

## Расширение

Для добавления новых типов устройств:

1. Создайте класс, реализующий `IThermometerDevice`
2. Добавьте логику подключения и получения данных
3. Добавьте устройство в список в `DevicesFragment.refresh()`
4. Обновите `UsbService.onCreate()` для создания нужного типа устройства

## Примечания

- Библиотека usbSerialForAndroid не изменялась
- Весь существующий код работы с USB сохранен без изменений
- Эмулятор работает полностью независимо от USB подсистемы
